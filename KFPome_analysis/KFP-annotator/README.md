# KFP-annotator

## Contents

### KFP_pipeline.sh

KFP-annotator master script for full KFPome analysis. 

### extract_KFPs.py

Extract sequences containing an extended beta-finger kinase domain from gene model representatives.

### count_beta_fingers.py

Count extened beta-finger kinase domains associated with each KFP and generate an itol annotation.

### annotate_auxiliary_modules.py

Identify the fused domain (auxiliary module) of annotated KFPs.

### generate_aux_module_itol.py

Generate an iTOL annotation based on the auxiliary modules of annotated KFPs.
