# Monocot Analysis

## Contents

### download_s_angustfolia.sh 

Download Streptochaeta angustfolia genome (contaminated so not typically included in monocot download).

### download_monocot_ref_genomes.sh

Download all available moncot reference genomes.

### get_species_name.py

Extract names of species of each downloaded genome assembly. (Table S3)

### annotate_genomes.sh

Annotate all genomes using HMM annotator.

### generate_itol_annotations.py

Generate annotation file of beta-finger presence for iTOL. (Fig. S22).

### generate_family_annotations.py

Generate annotation of monocot families for iTOL. (Fig S22. and Table S4).
